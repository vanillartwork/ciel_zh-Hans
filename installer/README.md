# 安装程序

Windows 安装程序，用 [NSIS](https://nsis.sourceforge.io/) 构建。

## 设计要点

**安装包里没有任何游戏文件。**

如果直接分发打包好的封包，安装包会有 1.7 GB，而且内容
**全部是游戏原始数据**——既涉及版权，也没必要。

所以安装包里只有：

```
payload/
  python/   可嵌入版 CPython + numpy + Pillow（约 35 MB）
  tools/    本项目的工具链
  data/     本项目的译文与术语表
```

补丁在**玩家自己的机器上**、用**玩家自己的游戏文件**生成。
代价是安装慢几分钟，换来的是安装包只有几十兆，且不含任何游戏内容。

## 构建

需要一台装了 NSIS 的 Windows 机器（`makensis` 在 PATH 上）。

```powershell
.\build-installer.ps1 -Version 0.9.0
```

脚本会：

1. 下载可嵌入版 Python，打开 `site-packages`
2. 装上 numpy 和 Pillow（重建字库需要）
3. 拷入 `tools/` 和 `data/`
4. **检查一遍 payload 里没有游戏文件**——发现 `.pak`、`.g1t`、
   `.psarc`、`.gtx` 或游戏 exe 就直接中止
5. 用 NSIS 编译

产物在 `../../dist/`，附带 `.sha256`。

## 安装程序做什么

| 步骤 | 失败时 |
|---|---|
| 从 Steam 注册表找游戏 | 让玩家手动选 |
| 确认目录里有 `CielnosurgeDX.exe` 和 `Res_x64` | 提示并要求重选 |
| 检查磁盘空间（6 GB） | 提示，让玩家决定 |
| `preflight.py` 核对版本 | **中止**，不改任何文件 |
| 释放 payload | 中止 |
| `build.py` 本地生成补丁 | **中止**，不改任何文件 |
| `install.py --apply` 备份并安装 | **自动回滚** |
| 清理临时文件、写卸载信息 | — |

**在生成补丁成功之前，游戏目录一个字节都不会被动。**

## 卸载

卸载程序调用 `install.py --restore`，从游戏目录的 `Backup`
还原三个原始文件。

还原失败时会明确告诉玩家：原始文件在哪，以及可以用 Steam 的
"验证游戏文件完整性"兜底。**不假设玩家知道怎么手工恢复。**
