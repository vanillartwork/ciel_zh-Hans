# 怎么编辑这些 CSV

译文文件是 UTF-8 的 CSV，单元格里可能包含**换行**。
编辑器选错了会把文件弄坏，所以这里说清楚。

## 推荐：LibreOffice Calc

免费，对 UTF-8 CSV 处理正确。

**打开时**（会弹出导入对话框）：

- 字符集：**Unicode (UTF-8)**
- 分隔选项：只勾 **逗号**
- 勾上 **将带引号的字段作为文本**
- 勾上 **检测特殊数字** —— **不要勾**

**保存时**：选"使用 Text CSV 格式"，编码 UTF-8，
字段分隔符 `,`，文本分隔符 `"`。

## Excel

Excel 能用，但有几个坑：

- **别双击打开。** 用「数据 → 从文本/CSV」，编码选 UTF-8。
- Excel 保存 CSV 时可能加 BOM。`validate.py` 会报错，
  重新跑一次 `dehydrate.py` 就能修正。
- Excel 会把看起来像数字或日期的内容自动转换。
  导入时把所有列设为**文本**。

## 文本编辑器

VS Code、Notepad++ 等直接编辑也可以，尤其是只改几行的时候。

注意：

- 保存为 **UTF-8（不带 BOM）**
- 换行用 **LF**（VS Code 右下角可以切换）
- 单元格里的换行要用**双引号包住整个字段**，
  引号本身在字段里要写成 `""`

## 更省事的办法

只改一两行的话，**根本不用下载文件**：
在 GitHub 网页上找到文件，点铅笔图标直接改，然后提交 PR。

## 改完检查一下

```bash
py -3 tools/validate.py
```

编码、BOM、换行、重复 id 这些问题它都会指出来。
