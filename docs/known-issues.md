# 已知限制

本页对应正在准备的 0.9.8。已发布版本的变化见[更新记录](../CHANGELOG.md)。

- 35 张状态标签图、33 张教程说明图尚未汉化；夏尔之巢的「構築中」气泡也仍是日文，资源尚未定位。
- 部分过场视频没有中文字幕，仍需核对语音、听写并制作时间轴。
- 少量长对白可能超出文本框。备忘录已调整折行，若仍有溢出，请附出现位置和截图。
- 摘要与备忘录的中文依赖显示层，按已知整句匹配；未匹配的内容保留原样。旧备忘的截断前缀若对应多个结果，不会自动补全。新备忘保留日文，但原版存储上限和文本框限制仍存在。
- 卸载不会回译旧版已经写入存档的中文，原版字库可能缺字。0.9.8 保留原文的具体范围见[存档说明](install.md#098-与已有存档)。
- 调试信息、程序查找键和输入过滤词表有意保留原文；启动器不在补丁范围内，环境设置程序已汉化。

诊断记录默认关闭。开启 `cielzh-trace.on` 会增加写盘开销，排查结束后请关闭，步骤见[安装指南](install.md)。

具体保留范围见[未汉化内容](not-translated.md)。
