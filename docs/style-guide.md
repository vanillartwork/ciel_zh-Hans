# 翻译规范

分两部分：

1. **[不能改的技术内容](#一不能改的技术内容)** —— 改了游戏会出问题
2. **[中文写法](#二中文写法)** —— 读起来像不像话

第一部分是硬性的，CI 会拦。第二部分靠人。

---

## 一、不能改的技术内容

### 尖括号标记

```
<CLBU>  <CLY1>  <CLY2>  <OUT>  <mess>     颜色/样式标记
<CR>                                       文本框内换行
```

**原样保留，位置也别动。**

颜色标记总是出现在行首，作用到整行：

```
原文：<CLBU>ありがと、慰めてくれて……。
译文：<CLBU>谢谢你，安慰了我……
```

`<CR>` 只出现在道具说明、帮助文本这类字段里，剧情对白里不会有。

**`<CR>` 可以少，不能多。** 中文比日文短，原文三行中文两行就说完了，
删掉一个 `<CR>` 没问题。但**多加一个可能把最后一行挤出文本框**，
所以 CI 把"多加"当错误，"减少"只提醒。

### 花括号

```
原文：{シェルノトロン}が暴走した
译文：{榭鲁诺特伦}失控了
```

**括号本身保留，里面的词按[术语表](../data/glossary/glossary.csv)译。**
游戏用这对括号标出可以查词典的术语，括号丢了词典就失效。

括号必须成对。数量也要和原文一致。

### 占位符

```
%s  %d  %5d  %-8s        程序填进去的值
$0$  $1$                  游戏内变量
```

**一个字符都不要改**，包括中间的数字和空格。`%5d` 里的 `5` 是
对齐宽度，改成 `%d` 会让排行榜的数字错位。

位置可以调整，以适应中文语序：

```
原文：あなたのランキングは   %5d位
译文：您的排名是   %5d位
```

### 换行

对白里的换行（真正的换行符，不是 `<CR>`）就是游戏里的换行。
同样：**可以少，不要多。**

### 字节上限

界面、道具、全局文本里有 `max_bytes` 列的，是**固定宽度的二进制字段**。
译文的 UTF-8 字节数必须小于这个数（要留一个字节给结束符）。

一个汉字 3 字节。`max_bytes` 是 12 就只能写 3 个字。

CI 会算，超了会报错。

### 可执行文件里的文本

`data/zh-Hans/executable.csv` 比较特殊：这些字符串直接**覆盖写**在
程序里，**长度绝对不能超过原文**。而且其中一部分刻意保留日文，
因为引擎可能按名字查找它们——`note` 列里写了每一条的理由，**不要去译它们**。

## 二、中文写法

### 标点

用**全角**中文标点：`，。？！、：；""''《》（）`

| 别用 | 用 |
|---|---|
| `、`（日文顿号用在并列）| 并列用 `、`，句中停顿用 `，` |
| `「」` | `""`（对白引用） |
| `～` | `—`（破折号）或直接删掉 |
| `...` / `。。。` | `……`（两个，占两格） |
| 半角 `,` `.` `?` `!` | 对应全角 |

**破折号用 `——`**（两个 U+2015），不是 `--` 也不是 `～`。

**省略号是 `……`**，六个点占两个字位，不是三个点。

### 数字

- 计数、数值、编号用**半角阿拉伯数字**：`3 次`、`Vol.12`、`Lv.5`
- 原文里的**全角数字保持全角**：`１０以上` → `１０以上`
  （这些多半是排版对齐用的，换成半角会错位）
- 成语、习惯说法用汉字：`一个人`、`三三两两`

### 人名与专有名词

**一律以[术语表](../data/glossary/glossary.csv)为准。**

- 标着 `官方` 来源的译名**不要改**，哪怕你觉得别的更好。
  统一比完美重要。
- 音译名之间的分隔符用 **`・`**（U+30FB），不是 `·` 也不是 `.`：
  `依欧娜萨鲁・库库鲁鲁・普立薛尔`
  （游戏字库里有这个字符，换别的可能显示不出来）
- 术语表 `forbidden` 列里的写法是**明令禁止**的，CI 会拦。

### 语气

这部作品的角色语域差别很明显，译文要体现出来：

| 角色 | 原文特点 | 中文处理 |
|---|---|---|
| 依恩 | 自称「わたし」，语气柔和、偏正式 | 温和有礼，不用网络用语 |
| 妮莉库 | 关西腔、活泼 | 轻快口语化，但不要用方言词 |
| 喵洛基 | 句尾「にゃ」 | 句尾加「喵」，不要每句都加 |
| 神官、军方 | 敬语、书面语 | 端正、偏书面 |

**「あなた」的处理：** 指玩家时译"你"。依恩对玩家说话时不用"您"——
她是在和一个亲近的人说话，不是在接待客人。

**不要用网络流行语。** 这部作品 2012 年发售，语感偏文学。

### 长度

原作自己的排版可以当尺子。统计全部 13 万行日文对白：

| | 中位 | 95% | 99% |
|---|---:|---:|---:|
| 日文每行 | 15 字 | 20 字 | 23 字 |
| 现有中文每行 | 12 字 | 19 字 | 21 字 |

也就是说**一行控制在 24 个全角字以内**，就落在原作自己的范围内。
超过时 CI 会提醒（只是提醒，不是错误——有些场合确实需要长行）。

真正危险的不是单行长，而是**行数变多**：原文两行的地方译成四行，
后面可能被文本框截掉。所以行数宁可减不要加。

写完读一遍：如果比原文明显长，多半还能再压。
中文说同样的意思通常比日文短，长了往往是翻译腔。

### 翻译腔

常见的几种，尽量避免：

| 别扭 | 自然 |
|---|---|
| 关于这件事，我认为…… | 这件事我觉得…… |
| 作为一个……的存在 | （直接说是什么） |
| 进行了一次确认 | 确认了一下 |
| ……的话，就…… | （很多时候"如果"都可以删） |
| 有着……的特征 | （直接描述） |

日文的「～のだ」「～ということ」「～に対して」大多不需要在中文里
找对应物，直接说意思就行。

### 拿不准的时候

在 `note` 列写下你的疑问，`status` 填 `needs-review`，
然后照常提交。写出来的疑问比藏起来的错误有价值得多。
