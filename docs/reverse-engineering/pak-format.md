# Gust PAK 封包格式

KTGL 引擎资源封包位于游戏的 `Res_x64/`。

| 文件 | 大小（约） | 主要内容 |
|---|---:|---|
| `PACK00_01.PAK` | 1.7 GB | 贴图、模型与字体图集 |
| `PACK00_02.PAK` | 2.3 GB | 其他资源 |
| `PACK00_03.PAK` | 1.1 GB | 其他资源 |
| `PACK01.PAK` | 33 MB | 剧情脚本、界面与数据表 |
| `PACK02.PAK` | 125 KB | 小型资源 |

## 结构

整数按小端存储：

```text
偏移 0    头部，共 16 字节
          u32  version      0x00020000
          u32  nb_files
          u32  header_size  16
          u32  flags

偏移 16   条目表，每条 168 字节（0xA8）
          char name[128]    异或处理后的文件名
          u32  size         文件内容大小
          u8   key[20]      条目异或密钥
          u64  offset       相对数据区起点
          u32  flags
          4 字节填充

数据区    从 16 + nb_files * 168 开始
```

文件名与内容使用该条目的 20 字节密钥循环异或。密钥全零时按明文存储。

文件名解码为以 `\0` 结尾的 UTF-8，使用反斜杠分隔路径，通常带前导反斜杠：

```text
\inc\event\res\01\ma01_tt01.txt
```

## 重建要求

`tools/gustpak.py` 的 `rebuild()` 保留原始 `raw_name` 字节及各条目密钥，重新计算大小与偏移。未修改内容不应因重新编码文件名而变化。

`tools/test_roundtrip.py` 用于检查无改动重建。受支持版本的 `PACK01.PAK` 为 33,781,160 字节，验证须比较完整内容。

异或处理在安装 NumPy 时对较大成员使用批量运算；小成员或无 NumPy 环境使用标准库实现。

## 内容分类

`PACK01.PAK` 共 3,750 个条目：

| 扩展名 | 数量 | 内容 |
|---|---:|---|
| `.txt` | 3,046 | 剧情脚本等 CSV |
| `.xml` | 248 | 界面布局 |
| `.bin` | 158 | 数据表 |
| `.inc` | 153 | 编译期生成的 C++ 片段 |
| `.gbd` | 72 | 事件历史数据 |
| 其他 | 73 | `.bas`、`.frm` 等 |

`.inc` 为随资源保留的编译期内容，不能仅凭其中存在相同字符串就认定该字符串是运行时查找键。相关判断见[可执行文件字符串](executable-strings.md)。
