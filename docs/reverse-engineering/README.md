# 格式资料

这里记录的是让文本能被**提取、翻译、写回**所需要的全部格式信息。

写下来有两个目的：让这个项目在原作者消失后还能维护，
以及让其他语言的社区不必把同样的路再走一遍。

| [binary-tables.md](binary-tables.md) | `.bin` 定长字段表 |
| [font-and-glyph-table.md](font-and-glyph-table.md) | 字体图集、字形表、PE 改造 |

## 范围限制

本项目**不包含也不接受**与 DRM、授权验证、防盗版、访问控制
等技术保护措施相关的分析、绕过或破解内容。

这不是客套话，而是一条实际的边界：本文档只涉及**资源容器格式与
文本编码**，因为不理解它们就没法做本地化。游戏的授权检查、
Steam 集成等部分既没有被分析，也不会被接受进这个仓库。
相关的 Issue 与 PR 会直接关闭。

## 关于原始资源

这些文档里**不附带游戏文件**，也不附带从游戏里导出的资源。

所有偏移、结构体和字段含义都以文字描述，
读者需要自己拥有游戏才能对照验证。举例用的数据都是结构示意，
不是从游戏文件里复制出来的内容。

## 记下来的教训

有几件事是**试错试出来的**，不写下来下一个人还会再踩：

1. **引擎只读封包。** 把散文件按相同路径放进游戏目录完全没有效果。
   曾经以为散文件覆盖能生效，为此浪费了不少时间。

2. **字体图集的尺寸不能改。** 引擎的 UV 除数不是从字体描述符里读的。
   把图集放大成 8192×8192、描述符改成 4096×4096，结果是每个字
   都按两倍高度采样——满屏乱码。腾地方只能靠删掉用不到的字形。

3. **字形坐标必须按块对齐。** 图集是 BC1 压缩的，4×4 一块；
   而且 UV 坐标是物理坐标除以 2。字形起点是奇数时，
   `x//2` 截断会让它和后面所有字形都偏移一个像素。

4. **不要重新序列化 CSV。** 原文件里部分字段带着多余的引号，
   用 `csv` 模块重写会把它们规范化掉，2,958 个脚本文件里有 19 个
   会因此产生差异。按字节区间替换才能保证只改该改的地方。

5. **改 exe 字符串前先查数据文件。** 有些字符串是引擎按名字查找的
   标签，它们同时出现在 exe 和运行时 `.bin` 里。
   只改 exe 那一份会让查找失配。

## 怎么自己验证

```bash
py -3 tools/test_roundtrip.py
```

空改动解包再打包，输出应当和原始封包**逐字节相同**。
这是理解正确的最直接证明。
