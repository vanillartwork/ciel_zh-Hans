# 文件格式资料

本目录记录本地化所需的资源容器、文本编码及字形结构，供维护和其他语言移植参考。

| [Gust PAK](pak-format.md) | 封包结构、异或处理与重建 |
| [剧情脚本](event-script.md) | CSV 字段与控制码 |
| [二进制数据表](binary-tables.md) | 定长字段与长度限制 |

| [可执行文件字符串](executable-strings.md) | 程序文本提取与替换 |

## 适用范围

资料面向[受支持的 Windows DX 版本](../supported-versions.md)，其他版本须重新验证偏移与结构。文档不附带游戏文件，验证需使用合法拥有的游戏。

本项目不包含或接受 DRM、授权验证、防盗版、访问控制等技术保护措施的分析或绕过内容，相关 Issue 与 Pull Request 将关闭。

## 关键约束

- 引擎从封包读取资源，散文件不能直接覆盖。
- 字体图集保持 8192×4096，UV 空间保持 4096×2048。
- 字形按 4×4 像素块对齐，避免压缩块冲突及坐标截断。
- 脚本按字段字节区间替换，保留未修改部分的原始字节。
- 程序字符串替换前须检查运行时数据引用，避免修改查找键。

无改动重建验证：

```powershell
py -3 tools/test_roundtrip.py
```

输出应与原始文件逐字节一致。
