# 剧情脚本格式

`inc/event/res/**/*.txt` 使用带 BOM 的 UTF-8 CSV，记录换行为 CRLF。文件扩展名不代表纯文本段落格式。

## 字段

列号从 0 开始：

| 列 | 内容 | 处理方式 |
|---:|---|---|
| 11 | 说话人名牌 | 按术语表翻译 |
| 12 | 对白正文 | 翻译 |
| 13 | `EVENT_PROCESS_*` 指令 | 保留 |
| 9、15、18、20、21、22 | 开发者注释 | 保留 |

部分指令的参数也包含可显示文本，提取范围由 `tools/export_text.py` 的 `CMD_TEXT` 定义。

对白字段内的实际换行对应游戏中的分行。译文可适当合并行数，增加行数则须验证文本框容量。

## 控制码

| 标记 | 含义 | 处理方式 |
|---|---|---|
| `<CLBU>`、`<CLY1>`、`<CLY2>`、`<OUT>`、`<mess>` | 颜色或样式 | 保留内容与作用位置 |
| `<CR>` | 文本框内换行，常用于道具及帮助文本 | 不得增加数量 |
| `{术语}` | 词典索引标记 | 保留花括号，翻译内部术语 |

## 写回方式

`tools/csvspan.py` 定位目标字段的字节区间，注入时只替换对应范围。不要重新序列化整个 CSV，否则可能改变原文件的引号、BOM 或换行。

无改动注入须与输入逐字节一致，验证命令见[格式资料索引](README.md#关键约束)。

## 说话人

第 11 列是显示用名牌；角色标识另由 `CHARA_*` 常量定义，可参考 `inc/event/charanamemap.inc`。

`export_text.py` 将说话人及出现频次导出到 `glossary_speakers.csv`。注入时需同时处理名牌和对白字段。
