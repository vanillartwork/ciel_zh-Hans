# 编译进可执行文件的日文

有一批提示文本不在任何数据文件里，而是在编译期就写进了
`CielnosurgeDX.exe` 的 `.rdata`。数据补丁碰不到它们。

扫描后得到 **377** 条面向玩家的字符串：确认对话框、
网络错误、菜单项、依恩的状态描述等。

## 提取

`tools/export_exe_text.py` 扫描 `.rdata` 里以 `\0` 结尾的 UTF-8 串，
筛选条件是：**含假名**且**至少两个 CJK 字符**。

含假名这一条很重要——不加的话，随机二进制数据里碰巧能解码成
汉字的片段会产生上千条噪声。

另外排除两类：

- `DEV`：调试与断言文本（含 `%s`、`::`、`ポインタ`、`失敗` 等特征）
- `ANIM`：动作计时标签（`～へ移動`、`工程開始` 等）

### 一个踩过的坑

最初的扫描正则只接受 `\xe3-\xe9` 开头的多字节序列，
也就是 U+3000–U+9FFF。结果 `※`（U+203B）、`★`、`®`、`＆`、
全角数字这些字符**把字符串从中间截断了**，扫出来一堆碎片。

碎片的问题是：它们在 exe 里永远无法作为"完整字符串"匹配上，
所以打补丁时会静默失败。修正正则（接受完整的 UTF-8 多字节范围）
之后，字符串数从 306 涨到 377，多出来的大部分是
`～しますか？` 这类确认对话框——恰恰是最常见的界面文本。

## 打补丁

**原地覆盖。** 散落在代码各处的 RIP 相对 `lea` 指令指向这些字符串，
搬走就得逐个重新定位，不划算。

代价是：**译文的 UTF-8 字节数不能超过原文**，多出来的用 `\0` 填充
（这只是让字符串变短，没有副作用）。

匹配时要求**前后都是 `\0`**，即必须是完整字符串。这样

```
"食器洗い"
```

就不会误伤

```
"食器洗い。空の食べ物を流しへ入れる、食器洗い…"
```

按原文长度**从长到短**替换，短串不会抢在长串前面。

验证：打完补丁后，全部 12,718 个改动字节都落在 `.rdata` 区间内，
文件大小不变，PE 节表不变。

## 哪些不能改

377 条里有 **59 条刻意保留日文**。分四类：

| 类别 | 例子 | 为什么 |
|---|---|---|
| 调试/断言 | `finalizeが２重呼び出しされました。` | 玩家看不到 |
| 动作计时标签 | `風呂。シャワー浴び始め` | 引擎可能按名字查 |
| 数据表字段名 | `端末の設置位置` | 同上 |
| 开发期测试串 | `一行テスト` | 无意义 |

每一条的理由都写在 `data/zh-Hans/executable.csv` 的 `note` 列里。

### 怎么判断一个字符串"不能改"

关键问题是：**引擎会不会拿这个字符串去和数据文件里的内容比对？**

`tools/check_exe_text.py --archives` 用来回答它。做法是扫描
运行时会读取的 `.bin` 和 `.xml`，看这个字符串是不是**填满了一整个字段**
（前后是 `\0`、逗号或换行）。

判断依据：

- **`.inc` 里出现不算数** —— 那是编译期生成的 C++ 源码片段，
  游戏运行时不读它。exe 里的那份才是唯一的副本。
- **`.txt`（剧本）和 `.gbd` 里出现不算数** —— 同一个词碰巧
  出现在对白里，说明不了任何事。
- **`.xml` 里出现要看位置** —— 实测命中的全都在 `<!-- 注释 -->` 里。
- **`.bin` 里作为完整字段出现才要警惕。**

用这个方法筛下来，318 条译文里只剩两条命中，都经人工确认过：

- `トイレ` 出现在 `point_data.bin`，但那一列是**显示名**，
  真正的键是旁边的 `ePOINT_YOME_TOILET`
- `HymPが足りません。` 出现在 `server_error_code_data.bin`，
  是服务器错误文案的**另一份独立副本**，不是查找键

至于 `かわいさ`、`セクシーさ` 这类，它们是 `.bin` 表头里的**列名**。
无法确认引擎是否按列名找列，而收益只是几个参数标签，
所以**保留日文**——这个取舍写在 `note` 里。

## 与字库补丁的顺序

先改字形表，**再**改字符串：

1. `build_font.py` 从**未打补丁**的 exe 出发，新增 `.fontex` 节
   （会改变文件大小与节表）
2. `patch_exe_strings.py` 在其结果上原地覆盖（不改大小）

反过来做，第 1 步会从原始 exe 重建，把第 2 步的改动丢掉。
