# 安装与卸载

## 安装前

你需要：

- **64 位 Windows 10 或更高版本**
- **已合法购买并安装的 Ciel nosurge DX**（Steam 版）
- **约 1 GB 可用磁盘空间**
- 几分钟时间

> 补丁不提供游戏本体。安装程序里没有任何游戏文件——
> 它读取的是你自己那份游戏。

## 安装

1. 从 [Releases](../../releases) 下载 `CielNosurgeDX-zh-Hans-<版本>-setup.exe`
2. 核对一下 SHA-256（可选，但建议）：

   ```powershell
   Get-FileHash .\CielNosurgeDX-zh-Hans-0.9.0-setup.exe -Algorithm SHA256
   ```

   应当和 Release 页面上那串一致。
3. 运行，按提示下一步。

安装程序做的事，按顺序是：

| 步骤 | 做什么 | 出错会怎样 |
|---|---|---|
| 找游戏 | 从 Steam 注册表里读，找不到就让你手动选 | 让你选，不会乱猜 |
| 核对版本 | 比对四个文件的 SHA-256 | **中止**，不改任何文件 |
| 查磁盘空间 | 至少 1 GB | 提示你，让你决定 |
| 释放工具 | 解压到 `%LOCALAPPDATA%\CielNosurgeDX-zh-Hans` | 中止 |
| 生成补丁 | 读你的游戏文件，重新打包 | **中止**，不改任何文件 |
| 备份 | 原始文件复制到游戏目录的 `Backup` | 中止 |
| 安装 | 替换三个文件，原地改写第四个 | **自动还原已替换的部分** |

**在"生成补丁"这一步之前，游戏文件一个字节都不会被动。**
即使中途失败或你直接关掉窗口，游戏也还是原样。

### 为什么要这么久

因为补丁不是现成的文件，而是在你的电脑上现做的。

如果直接分发做好的封包，安装包会有 1.7 GB，而且里面装的**全是游戏原始数据**——
既是侵权，也没必要。现在的做法是只带上译文和工具，
用你自己的游戏文件在本地生成补丁。下载只有几十 MB，且不含任何游戏内容。

## 会被改动的文件

```
CielnosurgeDX.exe            字形表 + 硬编码的日文字符串
CielnosurgeDX_Env.exe        启动环境设置的界面文本
Res_x64\PACK01.PAK           剧本、界面、道具等文本
Res_x64\PACK00_01.PAK        字体图集（只改其中 16.8 MB）
```

前三个文件的原版会整份复制到 `<游戏目录>\Backup\`。

`PACK00_01.PAK` 有 1.8 GB，但补丁只改其中的字体图集，
而且新图集和原图集**字节数完全相同**，所以是**原地覆盖那 16.8 MB**，
既不必重建整个封包，备份也只存被覆盖的那一段。

游戏目录下的其他文件、你的存档、Steam 云存档，都不会被动。

> **存档兼容。** 补丁只改文本和字形，不改存档格式。
> 装补丁前的存档能继续用，卸载后也还能用。

## 卸载

**推荐：** 设置 → 应用 → 应用和功能 → 找到"Ciel nosurge DX 简体中文补丁" → 卸载。

卸载程序会从 `Backup` 把原始文件放回去，包括原地改写的那 16.8 MB。

**如果卸载程序出了问题**，还有两个办法：

```bash
py -3 tools/install.py --restore
```

或者在 Steam 里：右键游戏 → 属性 → 已安装文件 → **验证游戏文件完整性**。
这会重新下载被改过的文件，一定能还原成原版。

> 你不需要知道怎么手工恢复。上面任何一个办法都够了。
> 就算 `Backup` 文件夹也被误删了，Steam 的验证功能仍然可以救回来。

## 遇到问题

### 安装程序找不到游戏

Steam 装在别的盘时会出现这种情况。点"浏览"手动选到包含
`CielnosurgeDX.exe` 的那个文件夹，通常是：

```
<某个盘>\SteamLibrary\steamapps\common\CielnosurgeDX
```

### 说"这个游戏版本不是本补丁所针对的版本"

意思是游戏文件和补丁预期的对不上。常见原因：

1. **游戏更新了。** 请到 Issues 反馈，附上安装程序打印的 SHA-256。
2. **装过别的补丁。** 先用 Steam 验证文件完整性还原，再装。
3. **文件损坏。** 同样用 Steam 验证。

这个检查**是故意做得严格的**：把一个版本的封包装到另一个版本上，
游戏多半直接起不来。宁可装不上，也不要装坏。

### 装完了，游戏还是日文

先确认安装程序最后确实显示成功。然后：

```bash
py -3 tools/install.py --verify
```

它会告诉你现在游戏目录里每个文件各是什么状态。

如果显示"原版"，说明替换没成功——多半是游戏正在运行，
或者需要管理员权限。关掉游戏和 Steam，用管理员身份重新运行安装程序。

### 游戏崩溃

先卸载补丁确认是不是补丁的问题。如果卸载后仍然崩溃，
那和补丁无关。如果卸载后正常，请开一个
[安装与运行问题](../../issues/new?template=bug.yml)，
把安装程序的详细输出贴上来。

## 手动安装（给开发者）

不用安装程序也可以：

```bash
py -3 tools/preflight.py                 # 先看能不能装
py -3 tools/build.py --version 0.9.0     # 生成
py -3 tools/install.py                   # 空跑，看看会改什么
py -3 tools/install.py --apply           # 真的装
py -3 tools/install.py --restore         # 还原
```

细节见 [build.md](build.md)。
